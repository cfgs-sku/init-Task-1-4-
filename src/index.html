# 图片 物料编码 物资名称 级 品牌 类目 规格型号 单位 平台链接 操作
💡 点击「+ 采购清单」可将物资加入本次采购；搜索不到的新物资请前往「如何赋码」了解操作

如何为新物资自动赋码？

系统会按照统一规则自动生成唯一编码，你不需要手动编写任何编码，只需按以下步骤操作。

1

先在数据库搜索，确认是否已有编码

点击顶部「物资数据库」，在搜索框输入物资名称关键词。如果搜到了，直接点「+ 采购清单」即可，不需要赋码。

💡 模糊搜索支持：输入"灭火"可找到"灭火器""灭火器箱""手提灭火器"等所有相关物资。
2

搜不到？去「采购清单」页手动添加并自动赋码

点击顶部「采购清单」→ 左侧搜索框输入物资名称 → 下拉没有匹配的 → 点「✦ 新增 xxx 并赋编码」。

接下来填写：
① 物资名称（已自动填入）
② 品牌、单位、规格（选填，建议填写）
③ 一级 → 二级 → 三级类目（必填，系统根据类目自动生成编码）
填完点「✦ 赋新码加入清单」，编码立即生成。
3

编码格式说明（了解即可，无需手动填写）

CSFW - AA - 01 - 01 - 004
──── ── ── ── ───
前缀 大类 中类 小类 序号

示例：CSFW-AA0101004
= 安防 / 安保设备 / 安保通讯设备 / 第4号
系统自动查找该三级类目下已有的最大序号，加1生成新编码，绝对不会重复。
4

有现成采购单？直接上传匹配

点击顶部「清单匹配赋码」→ 上传 Excel 采购单 → 点「开始匹配」。系统自动：

🟢 已有编码的物资 → 直接确认，同时补全规格
🟡 名称相似的 → 高亮提示，你确认是否同一物资
🔵 有三级类目的新物资 → 自动赋新编码
⚠ 无类目的 → 手动补充类目后重新处理
5

赋码完成后，把新记录存入数据库

在「采购清单」页底部点「💾 存入数据库」，本次新增的物资会永久保存。下次采购直接搜索即可，不需要重复赋码。

常见问题

🔤 不知道物资属于哪个类目怎么办？ ▶
参考以下对应关系：
• 对讲机、监控、警示牌 → 安防
• 插座、开关、电缆 → 电气
• 拖把、清洁剂、垃圾桶 → 清洁用品
• 打印纸、文件夹、订书机 → 办公用品
• 手套、安全帽、反光衣 → 个人防护
• 灯具、灯泡 → 照明
• 螺栓、螺丝 → 紧固件

不确定的，先选最接近的类目，后续可以修正。
♻️ 同一物资会不会生成两个编码？ ▶
不会。系统每次赋码前都先在数据库里搜索：
• 如果名称相似度 ≥90%，系统直接关联已有编码，不新建。
• 如果你上传的采购单已有编码字段，系统直接沿用，不重复赋码。
• 每个编码在系统里全局唯一，同一三级类目内按序号递增。
💾 数据存在哪里？关掉网页会丢失吗？ ▶
内置的 1978 条物资数据已编码在文件里，永久有效。
你手动添加并「存入数据库」的记录，保存在浏览器本地存储里（localStorage），同一台电脑同一浏览器重新打开不会丢失。
建议定期在「物资数据库」页点「导出数据库」做备份。
📤 如何把新编码同步给其他同事？ ▶
在「物资数据库」页点「导出数据库」，导出 Excel 后发给同事。
同事打开自己电脑上的系统，点「+ 导入更新」选择该 Excel，即可同步所有新增编码。
